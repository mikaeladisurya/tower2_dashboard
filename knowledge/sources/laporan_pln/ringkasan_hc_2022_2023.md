## Sustainability Report PLN 2022 (SR-PLN-2022.pdf) — GAGAL DIUNDUH

**URL:** `https://www.pln.co.id/webapi/media/file/webkorp/asset/SR-PLN-2022.pdf`
**Ukuran target (dari header server):** 66.985.302 bytes (~63,9 MB).

**Kronologi kegagalan:**
1. Percobaan otomatis pertama (sebelum bug diperbaiki): skrip unduhan mengasumsikan server selalu mendukung HTTP Range request untuk resume. Server PLN ternyata **mengabaikan header Range dan selalu mengirim ulang dari byte 0 dengan status HTTP 200** (bukan 206 Partial Content). Karena skrip tetap menambahkan (append) data baru ke file `.part` yang sudah ada, hasilnya adalah file korup sebesar 150 MB (lebih dari 2x ukuran target 67 MB). File korup ini **dihapus** sebelum lanjut, dan skrip diperbaiki untuk mendeteksi kondisi "server tidak mengembalikan status 206" dan mereset ke unduhan bersih alih-alih menambahkan data.
2. Dengan skrip yang sudah diperbaiki, dilakukan **5 percobaan resmi**, semuanya gagal dengan error yang sama (`RemoteProtocolError: peer closed connection without sending complete message body`) — koneksi diputus dari sisi server sebelum file selesai terkirim. Karena Range tidak didukung, tiap percobaan harus mengulang dari awal. Jumlah byte yang berhasil diterima sebelum putus, per percobaan: ±57,1 MB; ±27,3 MB; ±24,1 MB; ±29,1 MB; ±52,2 MB (dari target ±63,9 MB) — bervariasi dan tidak pernah mencapai 100%.
3. Pola ini konsisten dengan kegagalan `Statistik-2025` yang sudah dicatat di `ringkasan_hc.md` (masalah sisi server PLN untuk file besar, bukan masalah jaringan lokal yang konsisten).
4. File parsial (`.part`) terakhir **dihapus** — tidak ada file rusak yang tersisa di direktori tujuan.

**Dampak:** SR-2022 seharusnya memuat tabel komparatif 2020/2021/2022 (mengikuti pola SR-2023 yang terbukti memuat 2021/2022/2023). Karena unduhan gagal, **data tahun 2020 untuk PLN Induk (dan cross-check independen untuk 2021) TIDAK tersedia sama sekali dari task ini** — ini adalah satu-satunya sumber yang direncanakan untuk data 2020.

1. **Diklat Masa Purnabakti "Kerohanian" 2023** (SR-2023 hal. 172): tercetak Jumlah=552 untuk kolom 2023, padahal 260 (Pria) + 262 (Wanita) = 522 secara aritmatika. Diverifikasi visual terhadap gambar halaman — angka 552 memang tercetak apa adanya di sumber, bukan kesalahan ekstraksi teks. Baris "Jumlah" total 2023 (746) justru konsisten dengan 522+224=746 (bukan 552+224=776). SR-2024 (edisi lain, independen) mencatat Kerohanian 2023=522, yang cocok dengan hasil hitung 260+262. Kemungkinan sel "552" pada kolom 2023 adalah salinan tidak sengaja dari sel 2022 di baris yang sama (yang memang bernilai 552) — namun ini **tidak dikonfirmasi**.
2. **Dua definisi "turnover" berbeda dalam paragraf yang sama** (SR-2023 hal. 170): *"999 pegawai (2,6%) berhenti bekerja karena pensiun maupun sebab lainnya"* vs *"tingkat turn over adalah 52 orang atau 0,15%"*. Laporan tidak menjelaskan perbedaan cakupan kedua angka ini. Sebagai perbandingan, SR-2024/2025 memakai istilah "turnover" untuk angka yang skala persentasenya mirip dengan "999" (perputaran total ~2,6-2,7%, lihat `ringkasan_hc.md`), bukan mirip dengan "52" (0,15%) — sehingga penggunaan istilah "turn over" di SR-2023 tampak tidak konsisten dengan pemakaian istilah yang sama di edisi lain, atau memang mengacu ke definisi lebih sempit (kemungkinan pengunduran diri sukarela saja, tidak termasuk pensiun) yang tidak dijelaskan laporan.
3. **Basis populasi berbeda dalam SR-2023 itu sendiri**: tabel demografi utama (hal. 31/34/35) mencatat Total Pegawai 2023=38.542 (30.472 Pria+8.070 Wanita), tetapi tabel "Penilaian Kinerja" (hal. 174) mencatat basis "Total Pegawai PLN (b)" 2023=39.108 (31.019 Pria+8.089 Wanita) — selisih 566 orang. Pola serupa terjadi di 2022 (42.151 vs 42.547, selisih 396) dan 2021 (42.755 vs 44.237, selisih 1.482). Laporan tidak menjelaskan perbedaan basis populasi ini (kemungkinan tanggal cut-off berbeda antara data demografi tahunan dan siklus penilaian kinerja).
4. **Total Anak Perusahaan & Afiliasi**: angka agregat di tabel "Skala Usaha" (hal. 28: 2021=9.361, 2022=9.326, 2023=12.703) berbeda dari hasil penjumlahan tabel per-entitas anak perusahaan (hal. 35: 2021=9.235, 2022=9.191, 2023=12.614) — selisih 126/135/89 orang. Pola inkonsistensi ini SAMA seperti yang sudah dicatat sebelumnya di `ringkasan_hc.md` untuk SR-2024/SR-2025 (selisih serupa, ~85-90 orang untuk 2023/2024), mengindikasikan ini adalah pola berulang lintas edisi, kemungkinan karena cakupan entitas atau tanggal cut-off yang sedikit berbeda antara kedua tabel, tidak dijelaskan laporan manapun.
